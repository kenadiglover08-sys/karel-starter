# karel-starter

OVERVIEW:\
This s my work from Karel weeks of 10001 at TCU.
Karel is a robot that only knows four basic commands, so all of her behavior stems from those commands.

HOW TO RUN:\
Open the karel-starter folder in ad press the green Run button.
* Use run.ps1 on Windows or run.sh if you don't use the Run button.

WHAT I LEARNED:\
* Karel has no turnRight() command, so I created one using three turnLefts() calls in a method.
* I learned how to break problems into small tasks to give Karel a wider range of movements because Karel's command set is limited.
